Privacy Policy

Last updated: 16 November 2026.

Browser-based tools

Outshark's current image, text, password, conversion and calculator tools run locally in your browser. Files and text entered into these tools are not intentionally uploaded to Outshark for processing. Closing or refreshing the page typically clears the tool state.

Website hosting

Outshark is hosted on GitHub Pages. GitHub and network infrastructure may process standard request information, such as IP addresses, browser details and requested pages, to deliver and secure the site. Refer to GitHub's own privacy information for its processing practices.

Third-party resources

Some site pages load fonts from Google Fonts, which may process connection information. Links to GitHub and other websites are subject to those sites' policies. Outshark does not currently provide user accounts, payment collection, or an advertising account within its static website.

Future changes

If analytics, advertising, accounts, payments or external AI services are introduced, this notice must be reviewed and updated beforehand, including any applicable consent mechanisms.

Questions

You may report publicly shareable website questions through our contact page. Do not share confidential information in public GitHub issues.
